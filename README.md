# Synthsara Node Zero

A working, local-first browser prototype of Synthsara's consent, governance, WORTH, RTME, reflective AI, Universal Diamond Standard, and Witness Ledger layers.

## What works

- **Sarah Mirror:** local ethical reflection with explicit refusal of harm, coercion, and consent bypass.
- **Consent Vault:** granular permissions and a one-click global kill switch.
- **Witness Ledger:** append-only local audit history with JSON export.
- **RTME:** turns an intention into a vow, consent test, and concrete next action.
- **Synthocracy:** visible proposals and voluntary support/question votes.
- **WORTH:** a non-transferable demo contribution signal.
- **UDS:** an inspectable eight-pillar ethics gate.
- **Local-first storage:** all state remains in the browser via `localStorage`.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Current boundary

Node Zero is a functional prototype, not yet a production identity, cryptography, decentralized governance, or AI inference network. The next phase should add authentication, encrypted user vaults, signed Witness events, database-backed proposals, and an auditable model gateway.
